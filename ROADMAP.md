# ROADMAP.md

## Phase 1 — MVP (Current)

Core app: auth, guided testing, community DB, practice mode, bots.

Features: F-01 through F-20 (see `PLAN.md`).

---

## Phase 2 — Community Growth

- Comments on calibration entries
- User following / social graph
- Weekly "Community Calibration" featured entry
- Email digest of top community calibrations

---

## Phase 3 — Advanced Features

- AI-assisted statement formulation (help users phrase questions for accurate testing)
- Calibration comparison tool (your result vs. community average)
- Group/circle sessions (multiple users calibrate same subject, aggregate)
- Mobile app (React Native or Flutter)

---

## Phase 4 — Ecosystem

- Public API with API key auth (for third-party integrations)
- Hawkins Map of Consciousness interactive visualization
- Browser extension for quick calibration lookup
- Podcast/video integration (community-calibrated content library)
